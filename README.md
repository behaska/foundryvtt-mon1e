# Mon1e for Foundry VTT

Foundry VTT v14 Game System for **Mon** (Fringe Worlds). Version 0.0.1 (Bootstrap milestone): the system loads in Foundry; it has no rules, data models or sheets yet.

## Quick start
- Link this repository as `<User Data>/Data/systems/mon1e` (see [DEVELOPMENT.md](docs/DEVELOPMENT.md)).
- `npm ci`, then `npm run check` (typecheck + tests).
